# CastBox

A Spotify Connect-style audio receiver concept for Android.

## Overview
CastBox explores sending audio to an Android device over a local network or Bluetooth. The project includes Wi-Fi discovery using Android network service discovery (NSD) and a Bluetooth RFCOMM connection path.

## Project
- Platform: Android
- Language: Java
- Connectivity: Wi-Fi / NSD and Bluetooth RFCOMM

## Getting started
1. Clone the repository.
2. Open the Android project in Android Studio.
3. Sync the Gradle project and build the app.
4. Test on Android devices with the required connectivity permissions enabled.

## Notes
This is an independent project and is not affiliated with Spotify. Actual compatibility depends on the current implementation and the devices being tested.
